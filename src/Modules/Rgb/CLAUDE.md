# Session notes: Rgb

Past work on this part of Daisy's App, moved out of the root CLAUDE.md on 2026-10-26 (Claude Code reads this file only when it works in this folder). Entries touching several modules are in each one's notes. Keep it short: condense what's done.

- **3.11.0 (asked 2026-10-25: new Gaming sub-module RGB for motherboard / RAM / GPU lights without vendor software (the user's rig: ASUS TUF Gaming Z790-Plus WiFi with 9 ARGB fans, Trident Z Neo RAM, ASUS TUF RTX 5070 Ti); standard effects per device, a master OFF; "publish as 3.11"):** new module `src/Modules/Rgb/` (Gaming, GroupOrder 60). Protocols from OpenRGB's source (cloned to `%TEMP%\rgbref`, rewritten, not copied): `AuraUsb.cs` (HID 0B05 usage page FF72, EC 82/B0/35/36/3B/3F 55, 52 53 Gen1; board zone + one device per ARGB header), `NvidiaGpus.cs` (nvapi64 `nvapi_QueryInterface` ids, `NV_I2C_INFO_V3` port 1; ASUS subvendor 1043 → ENE at 0x67, EVGA 3842 + 1B06/1B80/1B81 → `EvgaGp102` zones, effects drawn by the hub at 30 fps; Off = black + mode 0 because this PC's FTW3 reads mode 1 back after a 0), `Ene.cs` (`EneChip` versions table, R-B-G, 0xAA keep; unknown versions never written), `Smbus.cs` (PawnIO: `PawnIoBus` loads the signed `PawnIO\SmbusI801.bin`/`SmbusPIIX4.bin` (PawnIO.Modules 0.2.11, LGPL, shipped), shared SMBus mutex; RAM remap off 0x77 as OpenRGB; `SmbusTask` via `ModuleTasks` elevated, since `pawnio_open` gives E_ACCESSDENIED without admin; found devices kept in `RgbSettings.Smbus`), `RgbHub.cs` (one thread, snapshot of settings on the caller's thread, `Save` once per `Owner`), `RgbView.cs` (Lights ON/OFF, Find Devices, All Devices + Set All, card per device, SMBus cards with Apply). Decisions (mine): hardware effects kept on the device (Aura commit, ENE 0xAA) so they survive restarts; devices never set here are left alone at start; RAM changes ask UAC each time (Apply batches effect/colour/speed); all RAM sticks one device; an ARGB header = one device (no per-fan control: the fans are a chain). This PC: TUF Z370-PRO (Aura on SMBus), EVGA GTX 1080 Ti FTW3, G.Skill F4-3600C16 Trident Z Neo ×4, PawnIO 2.0 installed (LibreHardwareMonitor). Tested: harness `%TEMP%\rgbtest` (`fake` 28 checks: RAM remap/set/keep, v2 GPU chip, Micron and unknown versions untouched, Aura packets byte by byte; `gpus`/`evga`/`drawn` on the real 1080 Ti without admin: found, red read back, rainbow 28 colours/3 s, restored; `task` unelevated → "PawnIO didn't open (0x80070005)"); DaisysDev: tab drawn, Breathing picked by UIA (`%TEMP%\rgbtest\pick.ps1`) drawn on the card, Lights OFF → black (also at the next start), ON → back, Set All → rainbow; its Rgb.json removed, card restored (name plate white, backplate off). Not tested on hardware: Aura USB, ASUS GPU ENE, RAM/older boards via PawnIO (needs the user's UAC), the "stop on its colour" at exit (DaisysDev was killed).
